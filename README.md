# OtoMAD Studio

**Create. Remix. Make It MAD.**

OtoMAD Studio is a browser-based audio editing platform designed to support 音MAD creation. Our goal is to make audio editing more accessible through intuitive tools, rhythm analysis, and AI-assisted workflows.

## Features

The current prototype supports:

- **Multi-track Audio** — Load multiple audio files.
- **Waveform Display** — View a simple waveform for each track.
- **Track Positioning** — Set the start time of each audio track.
- **Pitch Adjustment** — Change the pitch of individual tracks.
- **Volume Control** — Adjust track volume and master volume.
- **Audio Preview** — Listen to the combined mix.
- **WAV Export** — Export the finished mix as a WAV file.
- **Browser-based Processing** — Audio is processed locally in the browser and is not uploaded by the current prototype.

## Roadmap

Our development goals include:

- Audio trimming and advanced timeline editing
- Automatic rhythm and beat analysis
- Beat synchronization tools
- More audio effects and mixing controls
- AI-assisted audio editing
- Automated 音MAD generation

These features are planned development goals and are not necessarily available in the current version.

## Getting Started

1. Open OtoMAD Studio in a supported web browser.
2. Import one or more audio files.
3. Adjust the start time, pitch, and volume of each track.
4. Preview the combined audio.
5. Export your mix as a WAV file.

## Technology Stack

- HTML
- CSS
- JavaScript
- Web Audio API
- GitHub Pages

The current prototype is designed to run without a paid audio-processing API or a dedicated backend server.

## Project Status

OtoMAD Studio is an early-stage project under active development. Features, interface design, and technical architecture may change as development progresses.
